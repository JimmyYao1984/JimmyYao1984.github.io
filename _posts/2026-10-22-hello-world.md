## How to write a new post

Create a new file in the `_posts`{: .filepath } folder. The file name must
follow this format:

```
YYYY-MM-DD-your-post-title.md
```

For example: `2026-10-22-hello-world.md`{: .filepath }

Then start the file with the front matter below and write your content in
Markdown:

```yaml
---
title: "Your Post Title"
date: 2026-10-22 09:00:00 +0800
categories: Life
tags: [diary, notes]
---
```

Save it, commit, and push — GitHub Actions will build and publish the site
automatically.
